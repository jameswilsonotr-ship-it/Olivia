# IP-WQ-116 — `e` hop policy

**Status:** OPEN · **Date:** 2026-09-04

## Rule

`e` = hotter outfit **and** sheer. Never a single-hop photoreal+e.

Recipe: land `d` (same-cut sheer) first, then crop/hotter cloth as hop 2. Direct `e` refuse is a **card**, not a shrug.

## Acceptance

1. Dry-run prints the hop plan (`d` then `e-from-d`).
2. Photoreal + `e` in one generate/edit is refused by policy before the model.
3. Face-paint / identity smear on lane E → wipe pass before keep.
4. Partial land (romper, cloth returns to torso) is logged as PARTIAL, still kept if face+pose hold.
5. Outfit language only — never the word dress as the axis noun.
